# Lecturas usadas en la Tarea 2

Para cerrar esta fase he usado como apoyo los documentos metodológicos sobre auditoría de variables, definición del outcome y compromisos previos al modelado.

No se han usado para buscar rendimiento ni para elegir variables por asociación con el desenlace. Su papel es metodológico: ayudan a dejar fijados antes del modelado el predictimand, el caso positivo, el horizonte temporal, la gestión de censura y la auditoría de predictores.

En concreto:

- el documento de auditoría de variables se usa para clasificar predictores como admisibles, dudosos o excluidos;
- el documento C3 se usa para fijar outcome, caso positivo y horizonte;
- el manuscrito se usa como apoyo para mantener la lógica de decisiones previas, reproducibles y no dependientes del rendimiento.

Los documentos originales no se incluyen dentro del repositorio para evitar subir material interno o no publicado.
